## 1. `감성대화말뭉치(최종데이터)_Training.json`
AI-Hub에서 배포하는 **감성대화 말뭉치** 데이터셋입니다.
- 다운로드: https://aihub.or.kr (검색: 감성대화 말뭉치)
- 학습(`src/train.py`)에 사용되며, 사용자 발화(`HS`)와 감정 코드(E1~E6)를 추출해 긍/부정 이진 분류 데이터로 재가공합니다.

## 2. `reviews_merged_all.csv`
분석 대상인 커피 프랜차이즈 12개 브랜드의 앱스토어 리뷰 병합 데이터입니다.
(Google Play Store + Apple App Store, 전처리 완료본)
- 이 프로젝트에서 자체 수집한 데이터로, 별도로 준비해주셔야 합니다.
- 최소 `content`(리뷰 본문) 컬럼이 필요합니다.
